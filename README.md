# Nabire Resto — Web Pesan + Dasbor

- `index.html` — web publik (menu, keranjang, pesan via WhatsApp, peta ongkir)
- `admin.html` — dasbor pemilik (ringkasan, pesanan, menu, tampilan/tema, CRM, WhatsApp, migrasi, pengguna)
- `js/config.js` — **satu-satunya berkas yang perlu diedit**: isi `GAS_URL` dengan URL `/exec` Apps Script

Panduan lengkap: **PANDUAN-INSTALASI.md**.
Backend (`Kode.gs`, `Notifikasi.gs`, `CRM.gs`, `Migrasi.gs`, `appsscript.json`) dipasang terpisah di Google Apps Script — tidak ada di repo ini.
